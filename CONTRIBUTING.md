# Contributing

Thanks for improving Local AI Agent.

1. Open an issue for large behavior or security changes.
2. Keep changes focused and preserve the local-first approval model.
3. Do not add credentials, model weights, generated caches, or node_modules.
4. Run the checks in the README.
5. Include the manual scenario tested for UI, MCP, media, or connector changes.

For new tools, mark read-only and destructive behavior conservatively. Outward-facing account changes must require explicit approval.
